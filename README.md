# Meeting Moments To Momentum

黒ベースで海外の最先端SaaS（StripeやLinearなど）のような、洗練された「商談・会議AI要約ツール」のWebアプリを作ってください。

【デザイン要求】

・ダークモード基調、高級感と未来感のあるグラデーションやガラスのような質感（Glassmorphism）を取り入れる。

・シンプルかつ直感的で、プロフェッショナルな見た目。

【機能と画面構成】

・画面左側：会議のメモや書き起こしテキストを貼り付ける大きな入力エリア、および「AIで要約する」ボタン。

・画面右側：生成結果を以下の3つの綺麗に整列されたカードで表示する。

  1. 概要・要約（要点を箇条書き）

  2. 決定事項（合意した内容）

  3. 次回アクション（タスク、担当者、期限）

・生成されたテキストをワンタップで「コピー」できるボタンを配置する。
